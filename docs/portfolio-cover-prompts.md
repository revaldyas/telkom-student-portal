# Prompt Generate Cover Portfolio (TKJ & TJAT)

Satu prompt **per portfolio** (bukan per kategori). Data dari Payload (`/api/community/feed` + `/api/portfolios/:id`), portfolio berstatus `published`.

## Aturan gaya

| Tipe | Kapan dipakai | Gaya |
|---|---|---|
| **FOTO** | Karya berupa produk/perangkat fisik (router, server, PC, ODP, antena, alat ukur) atau hasil Implementasi | Foto realistis seperti kamera nyata, studio, softbox, backdrop charcoal-navy |
| **GRAFIS** | Karya berupa ide, desain, topologi, peta, dashboard, atau tahap Eksplorasi | Graphic design / blueprint, navy + garis putih/cyan + aksen merah |

Aturan tahap: judul tanpa tahap mengikuti sifat karya; **Eksplorasi** selalu GRAFIS (draft/blueprint); **Implementasi** selalu FOTO (hasil terpasang).

Semua gambar: rasio 4:3, tanpa teks, tanpa logo, tanpa wajah orang.
